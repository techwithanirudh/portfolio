Upload class notes and share them with a link, so a student who misses a class can get the notes from a classmate. I built it twice. The 2022 version began as Web Dev Simplified's Google Drive clone tutorial, which I rewrote and extended. The 2024 rebuild, Notes Buddy, started from the trevorpfiz/create-t3-turbo-supabase template.

The 2022 version is still up at notes-buddy.vercel.app, and the rebuild runs at notes.techwithanirudh.com. Both repos are private.

## How it works

The 2022 version is React on [Firebase](https://firebase.google.com/), with [Algolia](https://www.algolia.com/) search and hCaptcha on sign-up. It has a PWA that registers as a share target for image, audio and video files. New uploads wait in an approval queue for an admin app.

The rebuild uses [Supabase](https://supabase.com/) for email and Google sign-in, and Drizzle for the Postgres tables of profiles, folders and files. A folder can sit inside another folder. Folders and files are served through [tRPC](https://trpc.io/). Anyone signed in can browse them, and only the uploader can rename or delete.

Files go from the browser to Supabase Storage in 6MB chunks over its resumable endpoint, so a dropped connection picks up where it stopped. The Expo app never got finished.
