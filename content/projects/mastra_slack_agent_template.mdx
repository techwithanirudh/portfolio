A customizable Slack agent built with [Mastra](https://mastra.ai/), Bun and TypeScript, published as a GitHub template under the MIT license. It's community-maintained and not an official Mastra product.

## What it does

Mention it, message it or reply in a thread and it answers in Slack, streaming the reply as it works. It can search the web, generate images, hand work to helpers, run scheduled tasks and use skills and MCP servers. GitHub and AgentMail accounts are optional.

## How it works

Each thread gets its own [E2B](https://e2b.dev/) sandbox with files, a shell and a browser, and it stays around between turns, so later messages find the same files waiting. Memory is kept per thread in PostgreSQL, so conversations in a shared channel don't leak into each other. Posting to another channel is the one tool that asks you first.
