A starting point for a Slack agent that handles mentions, DMs, threads, files and streamed replies, and runs its commands in a sandbox. It's a GitHub template under the MIT license. Features get built in [Gorkie](/blog/gorkie-sandboxes) first and are ported here once they've survived a few rounds of fixes.

## How it works

Each thread gets its own [E2B](https://e2b.dev/) sandbox with files, shell access and a browser. The sandbox id is a hash of the Slack thread id, so later turns find the same files and tools waiting. The agent can hand work to three helpers that research, explore and build, and it searches the web through [Exa](https://exa.ai/). Posting to another channel is the one tool that asks you first.

Replies stream into Slack, and each tool call shows up as a step in a live card. A top-level mention makes the agent follow the thread. `##` at the start of a line keeps it quiet, and `!stop` cancels a running reply.

The agent runs `gh` and git with tokens it never holds. The sandbox only gets placeholder values, and the host adds the real Authorization header to GitHub and AgentMail requests on the way out.
