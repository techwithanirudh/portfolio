A Discord bot that talks in a server like another member instead of answering every message like an assistant. It started from Fellipe Utaka's Discord bot template and is open source under the MIT license.

It's inactive now. The last change to the main branch was in June 2025, and the code is still on GitHub.

## What it does

It chats in text channels, searches the web with [Exa](https://exa.ai/) and can join a voice channel to listen and talk.

## How it works

It always replies when you ping it, DM it or use one of its keywords. For other messages, a small model guesses whether they're about the bot. Replies are split into sentences with short random pauses and a typing indicator, and a rate limit keeps it from flooding a channel. One tool lets a second agent write and run discord.js code, so only the bot owner can use it.
