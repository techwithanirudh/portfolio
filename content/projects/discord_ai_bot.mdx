A Discord bot that hangs out in a server like another member, instead of answering every message like an assistant. It started from Fellipe Utaka's Discord bot template and it's open source under MIT. I'm not working on it anymore, but the code is still on GitHub.

## What it does

It chats in text channels, searches the web with [Exa](https://exa.ai/), remembers people with [Mem0](https://mem0.ai/) and can hop into a voice channel to listen and talk back, with [Deepgram](https://deepgram.com/) doing the listening.

## How it works

It always replies when you ping it, DM it or say one of its keywords. For everything else, a small model guesses whether the message is about the bot. Replies get split into sentences with short random pauses and a typing indicator, and an [Upstash](https://upstash.com/) rate limit stops it from flooding a channel. One tool lets a second agent write and run discord.js code, so only the bot owner gets to use that one.
