Fumadocs Starter is a docs site with an AI assistant, API reference pages, typed code samples and Markdown copies for AI tools already wired up. It starts from Create Fumadocs and is MIT licensed.

## How it works

An "Ask AI" panel answers from your own MDX. The chat route uses [AI SDK](https://ai-sdk.dev/) with `gpt-5-mini` and two tools. `searchDocs` queries the [Fumadocs](https://www.fumadocs.dev/) search index, and `getPageContent` returns one page as Markdown. The model used to list its own sources, but the links weren't always right, so the search tool writes them into the stream now.

OpenAPI specs become API reference pages, and [Twoslash](https://twoslash.netlify.app/) type-checks the code samples. The site also serves `llms.txt`, an RSS changelog and generated Open Graph images. Add `.mdx` to a docs URL, or send an `Accept` header that prefers Markdown, and you get the page as text.
