Fumadocs Starter is a ready-made docs site you can copy and fill with your own pages. It starts from Create Fumadocs and is MIT licensed.

It's a template, and the live demo is up.

## What it does

An "Ask AI" panel answers questions from your own docs. API pages are generated from an OpenAPI file, and [Twoslash](https://twoslash.netlify.app/) type-checks the code samples. Every page also has a plain Markdown copy for AI tools, and the site serves `llms.txt`, an RSS changelog and generated social images.

## How it works

The Ask AI panel searches the [Fumadocs](https://www.fumadocs.dev/) index with the [AI SDK](https://ai-sdk.dev/) and links the pages it used. Add `.mdx` to a docs URL and you get that page as Markdown.
