A ready-made docs site you can copy and fill with your own pages. It's built on Create Fumadocs, it's MIT licensed, and there's a live demo you can poke around.

## How it started

It began in March 2025 under a different name, Fumadocs MCP. The pitch in that first README was a [Fumadocs](https://fumadocs.dev/) site with Orama search, AI chat through the [AI SDK](https://ai-sdk.dev/) and room for an optional <Term>MCP</Term> server. The first real work was plumbing: Fumadocs' AI search dialog expected an "engine", so I wrote one that streamed answers from the AI SDK, and then spent a day fixing how it replaced the last message while the answer streamed in.

Two days later I started [Shadcn SaaS Landing](/projects/shadcn_saas_landing) on the same stack. The MCP name is gone now, and the repo is just Fumadocs Starter.

## Building it

By May 2025 it had `llms.txt` routes, so AI tools could read the whole site in one go. A v2 landed over the summer: newer Shiki and [Twoslash](https://twoslash.netlify.app/) so code samples are type-checked with real hovers, shared layout config, and an upgraded OpenAPI integration.

The AI chat got rewritten in December 2025. The old engine was replaced by a chat route on the newer AI SDK that streams the answer and lets the model call two tools: `searchDocs`, which queries the Fumadocs search index (optionally inside one section), and `getPageContent`, which pulls a whole page when a snippet isn't enough. The site's `llms.txt` goes into the system prompt so the model knows what exists before it searches. The panel shows each tool call as it runs and lists the pages the answer came from. In February 2026 the tool status got approval states and icons.

## How it works

Every page also has a plain Markdown copy for AI tools: add `.mdx` to any docs URL and you get it. The Open menu on each page links to that Markdown, to GitHub, or straight into an AI chat app with the page attached. On top of that the site serves `llms.txt`, `llms-full.txt`, an RSS changelog, a sitemap and generated Open Graph images.
