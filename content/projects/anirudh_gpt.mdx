AnirudhGPT is a chat app on top of the OpenAI API, with Google sign-in, saved conversations and optional web search. It ran on Replit in spring 2023. The repo is archived now and the Replit app is gone.

## How it works

Sign-in goes through [NextAuth](https://next-auth.js.org/) with Google, and [Firestore](https://firebase.google.com/docs/firestore) stores each user's chats and messages. The API route that calls OpenAI writes the reply into Firestore itself.

The chat API has no memory. So before each call the server reads every message in the current chat from Firestore and sends them all with a short system prompt.

With web search on, the app fetched nine results from a small [DuckDuckGo](https://duckduckgo.com/) scraper I ran on Replit. It rewrote the message into a prompt with the numbered results, the date and an instruction to cite links. The chat still showed what you typed.
