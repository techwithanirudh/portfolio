My own ChatGPT-style app on top of the OpenAI API, with Google sign-in, saved conversations and optional web search. I ran it on Replit back in spring 2023. The Replit app is gone now, but the code is still public (archived, under AGPL).

## What it does

You sign in with Google through [NextAuth](https://next-auth.js.org/), chat, and pick up your old conversations later. Turn on web search and it looks up a few results first, then answers with links.

## How it works

The chat API doesn't remember anything on its own, so before each call the server loads the whole conversation from [Firestore](https://firebase.google.com/docs/firestore) and sends it along. Search results came from a little [DuckDuckGo](https://duckduckgo.com/) scraper I ran on Replit.
