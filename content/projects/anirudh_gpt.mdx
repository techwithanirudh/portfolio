AnirudhGPT is a chat app on top of the OpenAI API, with Google sign-in, saved conversations and optional web search. It ran on Replit in spring 2023. The Replit app is gone and the repo is archived. The code is public under AGPL.

## What it does

You sign in with Google, chat, and come back to your old conversations later. With web search on, it looks up a few results first and answers with links.

## How it works

The chat API has no memory. So before each call the server loads the whole conversation from Firestore and sends it along. Search results came from a small DuckDuckGo scraper I ran on Replit.
