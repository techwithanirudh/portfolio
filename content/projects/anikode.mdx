AniKode is a drag-and-drop website builder on [GrapesJS](https://grapesjs.com/). You drag blocks onto a page, add custom HTML and JavaScript when you need more control, and keep several pages in one project. I built it three times, and the latest is AniKode Studio. Its landing page and sign-in are live, and the editor needs an account.

## How it works

In the dashboard you create a project, add pages and open one in the editor. After every change the editor posts the page's GrapesJS project JSON to that page's API route, which stores it in a Postgres column through [Drizzle](https://orm.drizzle.team/). The route checks the session and only touches pages owned by the signed-in user. If a save fails, the editor says so.

The editor panels are React components, so the editor follows the app's light and dark theme. Blocks sit in an accordion on the left, and tabs for styles, settings, layers and pages are on the right. Sign-in uses [NextAuth](https://next-auth.js.org/), with a magic link sent through [Resend](https://resend.com/) or a GitHub account.

## Earlier versions

The 2021 version was a GrapesJS page with more than 20 plugins that saved to IndexedDB. The 2022 version was a React app with an Express and MongoDB server.
