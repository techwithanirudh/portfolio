Coolify Tweaks is a [Stylus](https://github.com/openstyles/stylus) userstyle that changes the spacing, type and layout of [Coolify](https://coolify.io/)'s dashboard. It can also apply any [TweakCN](https://tweakcn.com/) theme, with no fork and no changes to Coolify's code. It isn't affiliated with Coolify.

It's live and maintained, and the latest release is v4.1.2.

## What it does

Projects turn into a grid of rounded cards, and pages like New Resource get cleaner rows. Install it with Stylus, or add it on the server with a [Traefik](https://traefik.io/) plugin so it works in any browser without an extension.

## How it works

The style is about 2,300 lines of SCSS aimed straight at Coolify's page structure. That's also its weak spot: a Coolify update every now and then breaks a few selectors, and I patch them in the next release.

Releases go up on GitHub, and a small [Nitro](https://nitro.build/) API sits in front of them. Your install link points at that API instead of a fixed file, so Stylus always pulls the latest release. Add a TweakCN theme ID to the link and the API fetches that theme, drops its colors into the style's CSS variables and loads its fonts, so any theme works without me shipping it.
