Coolify Tweaks is a Stylus userstyle that changes the spacing, type and layout of [Coolify](https://coolify.io/)'s dashboard. It can also apply any [TweakCN](https://tweakcn.com/) theme, with no fork and no changes to Coolify's code. It isn't affiliated with Coolify. Outside contributors sent fixes for header spacing, the select box icon and the show and hide button on disabled inputs.

## How it works

The style is about 2,300 lines of SCSS. A build writes `main.user.css` for [Stylus](https://github.com/openstyles/stylus) and a plain `main.css`, and each version ships as a GitHub release. Coolify's markup is Tailwind utilities and Alpine.js attributes, so my selectors anchor on structure, like the nav that holds the Dashboard link. There are 46 `:has()` selectors. Coolify updates still break some of them.

A [Nitro](https://nitro.build/) API serves the CSS from the latest release. Pass a TweakCN theme ID and it swaps that theme's variables and Google Fonts import into the stylesheet first. You can install it with Stylus, or through a [Traefik](https://traefik.io/) `rewrite-body` plugin that injects a `<link>` before `</head>`, so it works in any browser without an extension.
