Coolify Tweaks is a [Stylus](https://github.com/openstyles/stylus) userstyle that changes the spacing, type and layout of [Coolify](https://coolify.io/)'s dashboard. It can also apply any [TweakCN](https://tweakcn.com/) theme, with no fork and no changes to Coolify's code. It isn't affiliated with Coolify.

It's live and maintained, and the latest release is v4.1.2.

## How it started

It began in June 2025 as a single `style.user.css` file: a few fixes for spacing, toasts and that sponsorship popup. A day later it was a Stylus `.styl` file, and by the end of the month I'd thrown that out too and moved to SCSS split into partials, built with PostCSS. A small PostCSS plugin wraps the output in the `@-moz-document` block Stylus uses to decide which hosts to style, and another writes the userstyle header.

v3 came out in early July with a proper release workflow. That month I put [Phosphor](https://phosphoricons.com/) icons in the sidebar and redesigned the dashboard's project list into cards.

## The v4 rewrite

In October 2025 I rebuilt the whole thing as a [Turborepo](https://turbo.build/repo), starting from create-t3-turbo and ripping out what I didn't need (the Expo app, auth, the default API). The style became one app, and two new ones joined it: a [Nitro](https://nitro.build/) API and a docs site on [Fumadocs](https://fumadocs.dev/) with install guides, before and after screenshots and video walkthroughs. TweakCN themes came in with that rewrite too, and v4.0.0 shipped at the end of November.

## How it works

The style is about 2,300 lines of SCSS aimed straight at Coolify's page structure. That's also its weak spot: a Coolify update every now and then breaks a few selectors, and I patch them in the next release.

Releases go up on GitHub, and the Nitro API sits in front of them. Your install link (and the `@updateURL` in the userstyle header) points at that API instead of a fixed file, so Stylus always pulls the latest release. Add a TweakCN theme ID to the link and the API fetches that theme from TweakCN's registry, turns its colors into the style's CSS variables with PostCSS, adds a Google Fonts import for its fonts and runs the result through Lightning CSS for your browsers. So any theme works without me shipping it.

Don't want an extension? The second way in is Traefik's `rewrite-body` plugin, which injects the CSS into every dashboard response on the server, so it works in any browser on any device. You can also grab it from [userstyles.world](https://userstyles.world/style/22850/coolify-enhanced-ui).
