Coolify Tweaks is a Stylus userstyle that changes the spacing, type and layout of [Coolify](https://coolify.io/)'s dashboard. It can also apply any [TweakCN](https://tweakcn.com/) theme, with no fork and no changes to Coolify's code. It isn't affiliated with Coolify.

It's live and maintained, and the latest release is v4.1.2. Outside contributors sent fixes for header spacing, the select box icon and the show and hide button on disabled inputs.

## What it does

Projects turn into a grid of rounded cards, and pages like New Resource get cleaner rows. Install it with Stylus, or add it on the server so it works in any browser without an extension.

## How it works

It's about 2,300 lines of SCSS that target Coolify's page structure. Coolify updates still break some selectors, and I fix them in new releases.
