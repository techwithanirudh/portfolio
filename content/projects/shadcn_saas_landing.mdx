A SaaS marketing site in one project: landing page, pricing, blog, newsletter and a contact form. It's branded as a made-up product called SaasCN, and the README names [next-forge](https://next-forge.com/) and RunFunRun as inspiration.

It's a GitHub template.

## How it works

Each landing section is its own component. Pricing plans and both billing periods live in one data file that the plan cards and the comparison table read.

Blog posts are MDX with a date, author, tags and cover image. They feed the index, tag pages, RSS, the sitemap, a per-post Open Graph image and [Fumadocs](https://fumadocs.dev/) search. Comments use Fuma Comment with Better Auth and [Drizzle](https://orm.drizzle.team/), and the tables carry a `blog_` prefix so the template can share a database.

The contact and newsletter forms are [next-safe-action](https://next-safe-action.dev/) server actions that send through [Resend](https://resend.com/). A repeat newsletter sign-up is marked as subscribed again instead of creating a duplicate.
