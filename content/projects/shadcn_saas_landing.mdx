A whole SaaS marketing site in one project: landing page, pricing, blog, newsletter and a contact form. It's a GitHub template under MIT, and the live demo is branded as SaasCN, a made-up product.

## How it started

Fun fact: it started as the landing page for [AI Tutor](/projects/ai_tutor). I wanted an easy, reusable way to build that page, and then figured I might as well turn it into a template so other people could spin up a landing page just as easily.

The repo's first commit landed in March 2025, two days after I started [Fumadocs Starter](/projects/fumadocs_starter), and you can tell they're siblings: both run on [Fumadocs](https://fumadocs.dev/), even though this one isn't a docs site at all. I took inspiration from [next-forge](https://next-forge.com/) (and its creator Hayden Bleasel's own site), RunFunRun and Sunar.js.

## Building it

The pricing page has monthly and yearly tabs and a full plan comparison table, and both the plan cards and the table read from one `data.ts` file, so a price or a feature only changes in one place.

Then the blog, which is where Fumadocs earns its keep. Posts are MDX files with tags, an RSS feed and a collapsible table of contents. Comments use [Fuma Comment](https://github.com/fuma-nama/fuma-comment) with [Better Auth](https://www.better-auth.com/) sign-in and are stored in Postgres with [Drizzle](https://orm.drizzle.team/).

## How it works

Fumadocs indexes every post for its advanced search, which matches headings and paragraphs inside posts, not just titles. The contact and newsletter forms are [next-safe-action](https://next-safe-action.dev/) server actions that send email through [Resend](https://resend.com/), and new subscribers get a welcome email built with React Email.

## What happened after

In January 2026 I came back and upgraded it to Next.js 16 and the latest Fumadocs, rebuilt the Open Graph images with Takumi's `@takumi-rs/image-response`, and added env validation and a dev container. Right around then, this codebase also became the starting point for [my own site](/projects/portfolio): its first commit still had this template's inspiration list and the `blog_` table prefix.

Still on the TODO list: an "Ask Me Anything" AI chat on the blog using the Fumadocs Starter setup, a marquee footer and animated icons.
