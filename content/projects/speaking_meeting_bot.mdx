AI agents that join a Google Meet or Teams call and talk in it, each with its own personality. I wrote the first version in November 2024, and the Meeting BaaS team added more after that. It's open source under the MIT license and lives in the Meeting BaaS org now.

The hosted API still runs, and its docs page loads.

## What it does

You give it a meeting link and a persona, and the agent joins and holds a spoken conversation. A persona is a Markdown file that sets the agent's traits, voice and first line.

## How it works

[Meeting BaaS](https://www.meetingbaas.com/) joins the call and streams its audio. [Pipecat](https://www.pipecat.ai/) runs the voice pipeline, so [Deepgram](https://deepgram.com/) transcribes speech, an OpenAI model writes the reply and [Cartesia](https://cartesia.ai/) speaks it back. My version started each bot by script, each with its own [ngrok](https://ngrok.com/) tunnel. Today a FastAPI server starts them.
