This is my personal site, with a blog, my projects, a guestbook and an assistant named Simba. This page describes what's live on the main branch.

## How it works

Blog posts and project pages are MDX files that [Fumadocs](https://fumadocs.dev/) loads and indexes for search. [Drizzle](https://orm.drizzle.team/) and [Better Auth](https://www.better-auth.com/) handle the guestbook and comments. Entries can carry a drawn signature, and a model checks the message and the signature before saving. If that check fails for any reason, the entry is turned away.

Simba is named after my dog. Before each reply he gets a plain text index of the site: my profile, the page list, every post and project. He can search the content, read a page, open one for you or show the contact form already filled in. The server checks every page he opens against the real page list and refuses off-site links. The same content is served to other models through `/llms.txt`, `/llms-full.txt` and a raw `.mdx` route for each post and project.

Diagrams in posts are drawn on the server, so nothing shifts when they load. The About page reads my public GitHub events, looks up the commits in each push, and caches the result for five minutes.
