This is my personal site, with a blog, my projects, a guestbook and an assistant named Simba. It's live, and this page describes what's on the main branch.

## What it does

The blog and project pages are written in MDX. Search goes down to the matching line, and the guestbook takes a message and a drawn signature. Simba is named after my dog. He can search the site, open a page for you or show the contact form already filled in. The About page shows my recent public GitHub activity.

## How it works

[Fumadocs](https://fumadocs.dev/) loads and searches the MDX files. [Drizzle](https://orm.drizzle.team/) and [Better Auth](https://www.better-auth.com/) handle the guestbook and comments, and a model checks each entry before it's saved. The same content is served to AI tools through `/llms.txt`.
