Daily Diary is a journal app. Each entry is a dated page styled like a book, with prompts such as what you are thankful for or what you learned today.

It lived at diary.techwithanirudh.com and is offline now. The Internet Archive kept only the login page, so that's the one screen here.

## How it works

You sign in with [FirebaseUI](https://github.com/firebase/firebaseui-web) on [Firebase](https://firebase.google.com/) Authentication, using Google, Facebook, GitHub, email or phone. A helper button opens a five-step intro to the app, and a microphone button reads each step aloud with the browser's speech synthesis.
