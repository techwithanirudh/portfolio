This is the template extracted from Gorkie, the Slack assistant, so the same setup can be handed to anyone who wants their own. It runs as a long-lived Bun process and handles mentions, DMs, threads, files, and workspace search, streaming responses back into Slack with live tool-activity widgets rather than a single blob of text at the end.

The part that makes it useful is execution. Each thread gets its own isolated E2B sandbox with persistent files, shell access, and a browser, so the agent can run commands and inspect files without ever touching the host. Around that sit web research through Exa, image generation, subagents, and scheduled tasks, with optional GitHub and AgentMail accounts. New capabilities go in as skills or MCP servers rather than as forks of the runtime.

Models are routed through OpenRouter, memory and state live in PostgreSQL, and observability runs locally. The [configuration guide](https://github.com/techwithanirudh/mastra-slack-agent-template/blob/main/docs/configuration.md) walks through creating each service, since the template is only useful once the Slack app and credentials exist.
