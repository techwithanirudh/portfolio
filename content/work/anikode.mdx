AniKode is a drag-and-drop website builder. Start with simple HTML blocks, or add custom HTML and JavaScript when you need more control. You can add pages, move blocks around, and see the changes in the preview as you edit.

## How it works

The editor is built on GrapesJS, and you manage pages, blocks, and assets in one place. The editor saves each project as JSON, so the exported site matches what you built. Custom-code plugins let you add HTML or JavaScript when the built-in blocks are not enough.

NextAuth handles accounts and sign-in. The editor uses Next.js, Radix, and Tailwind.

## Stack

- Next.js 14, Tailwind CSS, Radix UI, Framer Motion.
- Drizzle ORM with Postgres adapters, NextAuth sessions.
- React Hook Form and Zod, React Email and Resend.
