Building a website usually means picking between a drag-and-drop builder that's too simple and a framework that's too much work. AniKode sits in between: a GrapesJS canvas for dragging blocks around, wrapped in a dashboard that saves every project through Drizzle so you can close the tab and pick it back up later.

Sign-in runs through NextAuth, and the editor itself, dialogs, menus, and configuration panels included, is built with Radix and Tailwind so it looks and behaves the same throughout. Project state is stored as plain JSON, which keeps exports and previews matching exactly what's in the editor.
