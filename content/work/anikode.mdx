AniKode lets you build a website by dragging elements onto a canvas instead of writing code. Add pages, place blocks, and edit content directly, with changes showing up live as you work.

Projects save automatically, so you can close the tab and pick a layout back up later. Accounts and sign-in are handled through NextAuth, and the editor itself is built with Next.js, Radix, and Tailwind.

<Tabs items={['Highlights', 'Stack']}>
  <Tab value="Highlights">
    - GrapesJS editor with export, form, and custom-code plugins.
    - JSON-based project persistence and live preview workflow.
    - Dashboard UX with editor panels for pages, assets, and settings.
  </Tab>
  <Tab value="Stack">
    - Next.js 14, Tailwind CSS, Radix UI, Framer Motion.

    - React Hook Form + Zod, React Email + Resend.
