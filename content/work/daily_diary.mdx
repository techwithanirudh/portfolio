Daily Diary is a small journaling app for jotting down daily reflections, built around guided prompts (gratitude, goals, lessons learned) instead of a blank page. It's built with React and Bootstrap, kept deliberately simple and readable on any device.

<Tabs items={['Highlights', 'Stack']}>
  <Tab value="Highlights">

    - Bootstrap-driven layout tuned for readability.
    - Client-only workflow ready for backend integration.
  </Tab>
  <Tab value="Stack">
    - React + Bootstrap.
    - Standard CRA-style build scripts.
    - Lightweight dependency footprint.
  </Tab>
