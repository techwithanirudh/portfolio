Daily Diary is a small journaling app for jotting down daily reflections, built around guided prompts instead of a blank page.

## Why it exists

A blank text box is intimidating for a daily habit. Guided prompts (gratitude, goals, lessons learned) give you something to respond to instead of a blinking cursor, which makes it easier to actually keep the habit going.

## How it works

Entries are composed, listed, and reviewed through a simple, readable interface. It's built with React and Bootstrap, kept deliberately lightweight as a frontend-only project.

## Stack

- React + Bootstrap.
- Standard CRA-style build scripts.
- Lightweight dependency footprint.
