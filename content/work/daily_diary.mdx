Daily Diary is a small journaling app for writing daily reflections. It uses prompts to help you get started.

## Purpose

Starting with a blank page can make journaling hard. Prompts for gratitude, goals, and lessons learned give you something to write about.

## How it works

You can write, list, and review entries in a simple interface. It is a frontend-only project built with React and Bootstrap.

## Stack

- React + Bootstrap.
- Standard CRA-style build scripts.
- Lightweight dependency footprint.
