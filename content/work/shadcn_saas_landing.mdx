Shadcn SaaS Landing is a ready-made SaaS landing page template with a built-in blog, keeping the product site and its content in one project.

## Why it exists

SaaS products need a polished marketing site and a place to publish updates, guides, and announcements. This keeps both in one template, sharing the same components and content pipeline.

## How it works

The marketing site is built with shadcn/ui components and Tailwind, with motion-driven UI touches. The blog runs on Fumadocs, giving it typed, searchable MDX content out of the box. For teams that want a data layer, Drizzle and Better Auth are already wired up, along with React Email and Resend for onboarding or contact flows.

## Stack

- Next.js 16, shadcn/ui, Tailwind, motion.
- Fumadocs MDX + Shiki + type tables.
- Drizzle ORM, Better Auth, React Email + Resend.
