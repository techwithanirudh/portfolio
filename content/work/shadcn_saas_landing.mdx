Shadcn SaaS Landing is a ready-made template that pairs a marketing site with a documentation section, so you're not stitching the two together yourself.

## Why it exists

SaaS products almost always need both a landing page and docs, and those usually end up as two separate projects with two different toolchains. This keeps them in one template, sharing the same components and content pipeline.

## How it works

The marketing site is built with shadcn/ui components and Tailwind, with motion-driven UI touches. The docs section runs on Fumadocs, giving it typed, search-ready MDX content out of the box. For teams that want a data layer, Drizzle and Better Auth are already wired up, along with React Email and Resend for onboarding or contact flows.

## Stack

- Next.js 16, shadcn/ui, Tailwind, motion.
- Fumadocs MDX + Shiki + type tables.
- Drizzle ORM, Better Auth, React Email + Resend.
