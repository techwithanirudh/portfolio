Coolify's dashboard works fine, but the spacing and typography could use some care. Coolify Tweaks fixes that with a Stylus userstyle that cleans up layout and type across the UI, backed by a Nitro API that serves the CSS dynamically so updates roll out without a manual reinstall.

The docs site walks through three ways to install it: a direct userstyle link, userstyles.world, or proxy injection, each with screenshots comparing before and after so it's easy to see what changed. It's all held together in a single TurboRepo, which keeps the style package, API, and docs in sync as the project grows.
