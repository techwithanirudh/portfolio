Coolify Tweaks is a userstyle that cleans up the Coolify self-hosting dashboard: better spacing, typography, and layout throughout. Install it via the Stylus browser extension or userstyles.world, or inject it directly if you're proxying Coolify through something like Traefik.

Docs walk through each install method with screenshots so you can see exactly what changes before you apply them.
