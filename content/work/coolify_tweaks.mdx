Coolify Tweaks changes the look of Coolify's self-hosting dashboard. It adds spacing, typography, and layout changes without changing Coolify itself.

## Purpose

Coolify works well, but parts of the dashboard feel cramped. This userstyle applies the changes without requiring a fork of Coolify.

## How it works

The CSS works in both light and dark mode. A Nitro API serves it, and you can install it through Stylus, userstyles.world, or a proxy such as Traefik. The site also shows what changes before you install it.

## Stack

- TurboRepo, TypeScript, Changesets.
- Stylus userstyles + Nitro API.
- Docs app with Tailwind UI utilities.
