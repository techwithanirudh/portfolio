Coolify Tweaks is a userstyle for Coolify's self-hosting dashboard. It changes the spacing, typography, colors, and layout without changing Coolify's code or requiring a fork.

## How it works

The userstyle adds CSS overrides on top of an existing Coolify dashboard. The rules work in light and dark mode and cover the main dashboard screens. A Nitro API serves the latest CSS. You can install it through Stylus, userstyles.world, or a proxy such as Traefik. The site shows the changes before you install them.

## Stack

- TurboRepo, TypeScript, Changesets.
- Stylus userstyles + Nitro API.
- Docs app with Tailwind UI utilities.
