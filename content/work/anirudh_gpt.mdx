A ChatGPT-style interface built to stay small and easy to change. AnirudhGPT wires Firebase into a Next.js app that mixes the newer App Router with older-style pages, so the chat views can look modern while the rest keeps a plain, familiar routing structure.

Firebase does the heavy lifting: Firestore stores the data, and admin access is set up for anything that needs to run server-side. The UI stays small on purpose, just Tailwind for layout and a handful of components, so changes to the chat flow are quick to make.
