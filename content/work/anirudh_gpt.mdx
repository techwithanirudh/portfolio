AnirudhGPT is a small chat app built on top of OpenAI, with sign-in and chat history handled through Firebase. Conversations are saved as you go, so you can close the app and pick up where you left off.

It's an early project, built as a compact Next.js UI rather than a polished product, with Tailwind for styling.

<Tabs items={['Highlights', 'Stack']}>
  <Tab value="Highlights">
    - Chat-first UI with reusable message components.
    - Firebase client + admin setup for Firestore access.
    - Simple routing split between `app` and `pages`.
  </Tab>
  <Tab value="Stack">
