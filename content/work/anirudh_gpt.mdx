AnirudhGPT is an AI chat app that uses the OpenAI API. You can sign in, save conversations, and come back to them later.

## How it works

The app is built from small message components. Firebase handles sign-in and Firestore stores the conversation history. It uses both the Next.js `app` and `pages` directories because it was built before I moved everything to the App Router.

## Stack

- Next.js, TypeScript, Tailwind, PostCSS.
- Firebase SDKs + Firestore.
- Minimal build scripts and config surface.
