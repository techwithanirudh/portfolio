Shadcn Portfolio is a beautifully designed portfolio starter that comes production-ready, built on Next.js 15 with shadcn/ui components and an MDX-driven content layer.

## Why it exists

Most portfolio templates need real work before they look finished. This one is meant to be closer to done on day one: clean section layouts, a blog pipeline, and SEO already wired up, so customizing it is mostly about swapping in your own content.

## How it works

Content for the blog and work pages is MDX, so writing a new post or project is just adding a file. shadcn/ui provides the accessible component layer, and Framer Motion adds the section transitions. SEO metadata, sitemaps, and structured data are set up out of the box, and a Turborepo workspace keeps tooling (linting, formatting) consistent if you extend it into more packages.

## Stack

- Next.js 15, TurboRepo, TypeScript.
- Tailwind + Radix via shadcn/ui.
- Framer Motion, dotenv, pnpm tooling.
