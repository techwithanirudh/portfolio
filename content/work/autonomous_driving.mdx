Self-driving cars record a lot of video, and that video usually has bystanders' faces in it. This research prototype swaps those faces out for a different one, so the footage can still be used to train driving models without keeping anyone's real identity in the data.

It works by mapping facial landmarks with MediaPipe, then warping a replacement face onto the same geometry with OpenCV, so the pose and expression still line up naturally. It also supports live webcam input, which made it easier to test the face swap in real time while building it.
