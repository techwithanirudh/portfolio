Self-driving cars record a lot of video, and that video usually has bystanders' faces in it. This research prototype swaps those faces out for a different one, so the footage can still be used to train driving models without keeping anyone's real identity in the data.

## Why it exists

Autonomous-driving datasets are full of people who never agreed to be recorded. Blurring faces protects privacy but throws away the facial geometry some models rely on. Swapping in a different, consistent face keeps that geometry intact while removing the real identity, which was the question this project set out to test.

## How it works

MediaPipe's Face Mesh maps out facial landmarks on both the original and replacement face. Those landmarks define a triangulation, and OpenCV warps each triangle from the replacement face onto the same geometry as the original, so pose and expression still line up naturally. It also supports live webcam input, which made it easier to test the face swap in real time while building it.

## Stack

- Python, OpenCV, MediaPipe, NumPy.
- Simple scripts for capture and mesh tooling.
