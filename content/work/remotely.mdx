Remotely lets you use a TV remote to control the pointer on a Mac connected to a TV. The arrows move the cursor, the centre button clicks, and nothing else needs to be bought or paired.

## Purpose

A Mac can be controlled from the couch without another device. macOS does not give apps direct access to TV remote buttons, but it writes those button presses to the system log. Remotely reads the log and moves the pointer.

## How it works

Tapping an arrow moves the pointer a little. Holding it moves faster. Press Back twice to switch the arrows to scrolling. You can also rebind twenty actions, including keyboard shortcuts. Everything runs on the Mac with no account or network connection.

## Stack

- Swift and SwiftUI, targeting macOS 15+.
- `RemotelyKit` core with no UI dependency, plus a menu bar app target.
- `CGEvent` input synthesis and Accessibility permissions.
- Swift Package Manager, with tests as a plain executable target.
