Fumadocs Starter is a template for documentation sites. It starts from Create Fumadocs and adds the parts most docs sites end up building by hand.

## How it works

An "Ask AI" panel answers questions from your own MDX. The model searches the docs and reads whole pages through tools, then streams an answer with its sources shown above it, so editing the docs is all it takes to keep it current.

OpenAPI specs turn into API reference pages, and Twoslash adds type-checked code samples with hovers and errors. The site also serves `llms.txt`, Markdown copies of every page, an RSS changelog, and generated Open Graph images.

## Stack

- Next.js 16, Fumadocs UI and MDX, Tailwind.
- AI SDK with OpenAI, Fumadocs OpenAPI and Twoslash.
- Bun, Ultracite and lefthook.
