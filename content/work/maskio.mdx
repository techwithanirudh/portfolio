Maskio is a pixel-art platformer: jump across platforms, dodge spiky hazards, and collect coins across multiple worlds.

## Why it exists

This was a project to learn KaboomJS by building something with an actual gameplay loop, rather than a single tech demo, complete with scenes, sprites, and collision handling.

## How it works

Levels are built from KaboomJS scenes with sprite-based collision detection for platforms, hazards, and coins. It works with keyboard controls on desktop and touch controls on mobile. esbuild bundles everything quickly, and a small Express server serves the build in both development and production.

## Stack

- KaboomJS, Node.js, Express.
- esbuild, nodemon.
- Lightweight scripts for build and serve.
