A browser game doesn't need a heavy toolchain to feel complete. Maskio proves that with KaboomJS: sprites, scenes, and collisions handle the gameplay, while esbuild bundles everything fast and a small Express server serves it in both development and production.

Gameplay logic lives entirely inside Kaboom's scene system, so the Node side stays focused on building and serving. Run `nodemon` in dev, bundle with `build.js`, and serve the output through that same lightweight Express server: no extra pipeline needed.
