Most Discord AI bots lock you into one model provider. This one doesn't. Discord AI Bot runs on Bun and TypeScript, pairs discord.js with the Vercel AI SDK, and lets you swap between OpenAI, Anthropic, OpenRouter, or Google without rewriting anything. It handles both text and voice, with speech tooling built into the same command pipeline.

Commands, event handling, and AI tool execution are all kept modular, so adding a new skill doesn't mean touching the core. Voice runs on Discord's own voice stack plus Deepgram and ElevenLabs, and Upstash Redis rate-limits requests so long-running ones don't cause trouble.
